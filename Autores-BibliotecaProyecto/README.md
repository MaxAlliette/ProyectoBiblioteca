# Autores-BibliotecaProyecto
Microservicio que contiene catálogo de autores del proyecto de biblioteca para asignatura Desarrollo Fullstack I.

URL para obtener todos los autores en postman:
GET
localhost:8081/api/v1/autores

URL para obtener un autor por ID en postman:
GET
localhost:8081/api/v1/autores/{n° de id}

URL para agregar un autor en postman:
POST
localhost:8081/api/v1/autores

URL para actualizar un autor en postman:
PUT
localhost:8081/api/v1/autores/{n° de id}

URL para eliminar un autor en postman:
DELETE
localhost:8081/api/v1/autores/{n° de id}
