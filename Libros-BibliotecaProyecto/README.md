# Libros-BibliotecaProyecto
Microservicio que contiene catálogo de libros del proyecto de biblioteca para asignatura Desarrollo Fullstack I.

URL para obtener todos los libros en postman: GET localhost:8082/api/v1/libros

URL para obtener un libro por ID en postman: GET localhost:8082/api/v1/libros/{n° de id}

URL para agregar un libro en postman: POST localhost:8082/api/v1/libros

URL para actualizar un libro en postman: PUT localhost:8082/api/v1/libros/{n° de id}

URL para eliminar un libro en postman: DELETE localhost:8082/api/v1/libros/{n° de id}

URL para buscar un libro por su titulo en postman: GET localhost:8082/api/v1/libros/buscar?titulo={Nombre del Libro}

URL para obtener un libro por ID de su categoria en postman: GET localhost:8082/api/v1/libros/categoria/{n° de idCategoria}
